# Tailwind

Utiliser :

- classes lisibles
- spacing coherent
- responsive mobile-first
- composants reutilisables quand une structure revient
- couleurs du theme quand elles existent

Eviter :

- classes inutiles
- styles inline
- valeurs arbitraires sans raison visuelle
- duplication excessive de grands blocs de classes

Breakpoints :

- `sm`
- `md`
- `lg`
- `xl`
- `2xl`

Controle :

- texte dans les boutons sans debordement
- cartes stables au hover
- grilles lisibles sur mobile et desktop
