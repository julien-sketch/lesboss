# Conversion Marketing

Toujours appliquer :

- benefices avant fonctionnalites
- CTA visibles immediatement
- objections traitees dans la FAQ ou les textes courts
- friction minimale pour reserver ou contacter
- preuve de credibilite quand elle existe

Le visiteur doit comprendre :

- ce que sont Les Boss
- pour qui sont les evenements
- pourquoi c'est different
- quelle action faire ensuite

Structure recommandee :

1. Hero clair
2. Concept / promesse
3. Chiffres ou preuves
4. Prochain evenement
5. Principes / benefices
6. FAQ
7. CTA final

Regles :

- un CTA principal par section importante
- textes courts et concrets
- eviter les promesses vagues
- ne pas surcharger le visiteur
