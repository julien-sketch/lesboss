# Event Branding

Objectif :
Faire sentir que Les Boss cree des evenements, pas seulement des pages web.

Principes :

- chaque page evenement peut avoir une direction artistique propre
- garder le lien avec la marque Les Boss : noir, blanc, jaune, ton direct
- utiliser les visuels reels quand ils existent
- privilegier les compositions immersives pour les evenements
- ne pas enfermer toutes les pages dans le meme systeme de cartes

Pour une page evenement :

- hero immersif
- date, lieu, heure et prix visibles rapidement
- CTA reservation visible
- programme facile a scanner
- ambiance traduite visuellement
- responsive sans perdre l'effet affiche

Interdictions :

- page evenement generique
- visuel important trop petit
- texte qui couvre une information essentielle de l'image
- surcharge decorative sans fonction
