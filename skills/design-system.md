# Design System

Style general :

- premium accessible
- moderne
- professionnel
- vivant
- legerement decale

Interdictions :

- design generique SaaS
- gradients violets ou bleus generiques
- animations inutiles
- ombres excessives
- sections decoratives sans fonction
- textes trop longs dans les cartes

Typographie :

- conserver la typographie actuelle du projet sauf demande explicite
- hierarchie tres marquee
- titres forts et courts
- textes faciles a scanner
- alignement propre, de preference a gauche sauf sections courtes centrees

Palette :

- noir / ink
- blanc / paper
- jaune Les Boss / punch
- gris neutres
- accents secondaires uniquement si le sujet l'exige

Mise en page :

- utiliser une grille claire
- respecter une baseline 8px autant que possible
- garder de vrais espaces de respiration
- eviter les cartes imbriquees
- aligner les sections sur des largeurs coherentes

Objectif :

Donner une impression de valeur, de clarte et d'energie des les premieres secondes.
