# Grid System

Objectif :
Structurer les pages Les Boss avec une grille claire, premium et responsive.

Principes :

- construire les pages sur une logique de grille 12 colonnes
- utiliser une baseline 8px
- aligner titres, textes, boutons et cartes sur des axes visibles
- garder une composition asymetrique quand elle sert la lecture
- limiter les largeurs de texte pour preserver la lisibilite
- laisser respirer les sections importantes

Responsive :

- mobile first
- eviter les textes minuscules illisibles
- eviter les grilles trop serrees sur mobile
- conserver des dimensions stables pour cartes, boutons et pictogrammes
- verifier que les longs mots et titres ne debordent pas

Interdictions :

- elements poses au hasard
- espacements incoherents entre sections similaires
- colonnes trop nombreuses sur mobile
- hero ou cartes qui creent des vides inutiles

Controle rapide :

1. La section se comprend-elle en moins de 5 secondes ?
2. Les alignements sont-ils visibles ?
3. Le CTA principal est-il evident ?
4. Le mobile garde-t-il la meme intention que le desktop ?
