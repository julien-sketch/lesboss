# Next.js

Toujours utiliser :

- App Router
- TypeScript
- Server Components sauf besoin client explicite
- composants simples et maintenables

Bonnes pratiques :

- metadata SEO pour les pages publiques
- images optimisees avec `next/image`
- imports propres
- eviter les doublons de donnees
- limiter les dependances inutiles
- verifier `npm.cmd run lint`, `npm.cmd run typecheck` et `npm.cmd run build`
