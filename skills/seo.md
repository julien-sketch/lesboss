# SEO

Objectif :
Creer des pages techniquement propres, lisibles par Google et utiles pour les visiteurs.

Regles :

- une seule balise H1 par page
- H2 structures
- metadata complete pour les pages importantes
- URLs propres
- images importantes avec texte alternatif
- structure HTML semantique
- textes humains avant mots-cles

Pour chaque page importante :

- title
- description
- H1 clair
- introduction comprehensible
- contenu utile
- CTA

Next.js :

- utiliser `metadata` dans App Router
- utiliser `next/image`
- eviter le JavaScript inutile
- privilegier les Server Components quand possible
