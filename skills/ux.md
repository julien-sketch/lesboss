# UX

Objectif :
Creer une experience simple, claire et agreable.

Principes :

- le parcours doit etre evident
- chaque page doit avoir un objectif clair
- chaque section doit guider vers l'action suivante
- reduire les frictions
- eviter les textes longs si une phrase courte suffit
- rendre les CTA visibles et comprehensibles
- conserver une navigation simple

Pour Les Boss :

- privilegier le ton direct
- expliquer sans jargon reseau/business club
- rassurer les personnes qui viennent seules
- montrer que l'ambiance facilite les rencontres
- eviter les interfaces trop institutionnelles

Mobile :

- boutons faciles a toucher
- titres lisibles
- pas de chevauchement
- cartes empilees proprement
- images cadrees sans masquer l'information essentielle
